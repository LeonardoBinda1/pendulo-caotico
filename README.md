# Manuscript with updated figures 3 and 5

Import this ZIP into Overleaf, select main.tex, and compile with pdfLaTeX.
The title and two-column REVTeX 4.2 layout are retained. Author placeholders
remain to be completed by the authors.

Figures 3 and 5 have been replaced, and their captions, interpretation,
numerical protocols, dimension estimates, and conclusions have been updated.
Figure 3 varies both damping and torque amplitude. Figure 5 explicitly
separates the weak-perturbation manifold example from the finite-damping
attractor used for dimension estimation.

The supplied PDFs suffice for compilation; regeneration is optional.
Run `python reproduce.py` to regenerate all figures. This can take several
minutes and requires numpy, scipy, matplotlib, and numba.

- figures/: current manuscript figures, PDF and PNG.
- supplementary/updated/: current Python program and standalone Jupyter
  notebook, validation reports, alternative fixed-damping gallery and
  scale-window / matched-sample step-refinement diagnostic.
- supplementary/legacy/: original calculation and arrays for unchanged
  figures 1, 2 and 4. Superseded figures 3 and 5 can be generated there for
  comparison, without overwriting the active manuscript figures.
- source_original/main.tex: original uploaded source, preserved unchanged.
- ALTERACOES_FIGURAS_3_5.md: focused notes on this update.

Large updated trajectory arrays are generated by the code and not bundled.
Grid-origin ranges are numerical sensitivity ranges, not statistical
confidence intervals. Dimensions are finite-resolution estimates.
